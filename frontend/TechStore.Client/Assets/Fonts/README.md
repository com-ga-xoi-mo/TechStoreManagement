# Plus Jakarta Sans

`PlusJakartaSans.ttf` is the variable weight font from Google Fonts:
https://github.com/google/fonts/tree/main/ofl/plusjakartasans

It is distributed under the SIL Open Font License 1.1 in `OFL.txt`.
The category workspace uses local files for offline typography. Static weight files come from
https://github.com/tokotype/PlusJakartaSans/tree/main/fonts/ttf
and are covered by the same OFL license. `PlusJakartaSans.ttf.manifest` maps weights
400/500/600/700 to static files on Skia, following
https://platform.uno/docs/articles/features/custom-fonts.html .

Workspace icons are original line geometry authored in `CategoryWorkspaceStyles.cs`; they do not require an external icon font.
