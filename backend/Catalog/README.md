# Module Catalog (Dev 2 phụ trách)

Nội dung triển khai:
- Entities: `Product.cs`, `Category.cs`, `ProductVariant.cs` (Kế thừa từ `BaseEntity`).
- Specs JSONB: Cấu hình thông số kỹ thuật động (CPU, RAM, Pin, Màn hình...) trong EF Core.
- Fluent API Configurations trong thư mục `Configurations/`.
- Services: `ICatalogService.cs`, `CatalogService.cs`.
- Controller: `ProductsController.cs`.
